# Simulador-banco
Este repositório é o resultado de um desafio proposto pelo curso "Luizalabs - Back-end com Python - 2º Edição". O programa simula um ambiente de sistema bancário acessível a um cliente convencional.

## Desafio

Atualizar a implementação do sistema bancário, para armazenar os dados de clientes e contas bancárias em objetos ao invés de dicionários.
